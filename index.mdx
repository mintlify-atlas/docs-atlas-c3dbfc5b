OpenSwarm is a fully open-source multi-agent AI system that gives you a complete AI team from your terminal. Instead of one model trying to do everything, you get specialists — an Orchestrator that routes work, and dedicated agents for research, data analysis, slides, documents, images, video, and even house music production. Install in 30 seconds with npm, connect your API keys, and start creating.

## What OpenSwarm can do for you

Send one prompt and watch specialists collaborate automatically. The Orchestrator interprets your goal, dispatches the right agents in parallel or in sequence, and delivers a unified result.

## Get started in 3 steps

<Steps>
  <Step title="Install via npm">
    ```bash
    npm install -g @vrsen/openswarm
    openswarm
    ```
    Node.js 20+ is required. Python 3.10+ is auto-installed during setup.
  </Step>
  <Step title="Add your API key">
    The interactive setup wizard walks you through choosing an AI provider (OpenAI, Anthropic, or Google Gemini) and entering your key. Optional add-ons for Composio, web search, image generation, and video are configured in the same wizard.
  </Step>
  <Step title="Send your first prompt">
    Type any task — "Create an investor pitch for my startup", "Research my top 5 competitors", or "Analyze this CSV and build charts" — and the Orchestrator routes the work to the right specialists automatically.
  </Step>
</Steps>

<Note>
  OpenSwarm is built on [Agency Swarm](https://github.com/VRSEN/agency-swarm). Tools gracefully degrade when optional API keys are missing — you'll get clear instructions on what to enable for each capability.
</Note>
